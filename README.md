# Визуальный редактор · Runepost Labs

Визуальный редактор HTML-писем: правка текста, ссылок и картинок прямо в
превью письма, с подсветкой нужного места в коде.

**Живой инструмент:** https://vmakarov-dev.github.io/visual-editor-for-email/

## Возможности

- Вставьте HTML-код письма — справа появится превью. Клик по тексту,
  ссылке или картинке открывает окно правки; изменения сразу попадают в код.
- Видимые неразрывные пробелы и прочие скрытые символы в поле правки,
  начертания (жирный, курсив, зачёркнутый).
- Тумблер «Скрытые блоки»: показывает всё, что на текущей ширине скрыто
  (мобильные блоки на десктопе и наоборот), обводит пунктиром. Включён по
  умолчанию, если такие блоки в письме есть. Прехедер не показывает. На
  скачиваемый HTML не влияет.
- Список всех ссылок письма с предупреждениями о подозрительных адресах.
- UTM-метки для ссылок (модуль `utm.js` / `utm.css`, отключается двумя строками
  в `index.html`).
- Превью для десктопа и мобильного, светлая и тёмная тема.
- Копирование и скачивание готового `.html`.

## Запуск

Чистые HTML, CSS и JavaScript — без сборки и зависимостей. Достаточно
открыть `index.html` в браузере (работает и по `file://`, без интернета).

Шрифты IBM Plex лежат в `fonts/` (SIL Open Font License 1.1).
